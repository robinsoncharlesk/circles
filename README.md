# Circles - A Mindful Social Media App

**By an educator, for humans who want meaningful connections.**

## What is Circles?

Circles is a social media app designed to fight addiction and foster genuine human connection.

**Core Philosophy:**
- ❌ No likes, no ads, no endless scrolling
- 🔒 Privacy-first with content expiration
- 🎯 Organized around personal 'circles' (Family, Friends, Work, Inner Circle)
- 🧘 Mindful design that respects your time and mental health

## How to See Your App Running

### Step 1: Install Node.js
You need Node.js on your computer. It's like the engine that runs JavaScript.
- Go to: https://nodejs.org
- Download the "LTS" version (the stable one)
- Install it

### Step 2: Install Expo Go on Your Phone
- **iPhone:** Get "Expo Go" from the App Store
- **Android:** Get "Expo Go" from the Google Play Store

This app lets you see your Circles app running on your phone!

### Step 3: Set Up This Project
Open a terminal (Mac/Linux) or Command Prompt (Windows) and:

```bash
# Go to your circles folder
cd circles

# Install all the dependencies (this downloads needed software)
npm install

# Start the app!
npm start
```

### Step 4: View on Your Phone
1. After running `npm start`, you'll see a QR code
2. **iPhone:** Open Camera app, point at QR code, tap notification
3. **Android:** Open Expo Go app, tap "Scan QR Code"
4. Your app will load on your phone!
